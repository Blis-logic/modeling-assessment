# 모델링 탐구 수행평가

전문 수학 · 삼각함수·미적분 수학적 모델링 탐구 수행평가(40점) 웹 앱입니다. 학생은 아이디·비밀번호로 가입해 5단계 활동지를 쓰고, 교사는 작성 현황을 실시간으로 보며 채점합니다.

- **화면**: 이 저장소의 `index.html`을 GitHub Pages로 배포합니다. 학생은 구글 계정 없이 접속합니다.
- **저장 서버**: `apps-script/Code.gs`를 구글 스프레드시트의 Apps Script에 넣어 웹 앱으로 배포합니다. 계정·기록·채점은 그 스프레드시트에 쌓입니다.
- **연결**: `config.js`의 `apiUrl`에 Apps Script 웹 앱 주소를 넣습니다.

## 설치 (처음 한 번)

### 1. 저장 서버 (구글 Apps Script)

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. 학교 Workspace 계정이 외부 접근을 막고 있다면 **개인 Gmail 계정**으로 만듭니다.
2. **확장 프로그램 → Apps Script**를 열고, `Code.gs` 내용을 모두 지운 뒤 이 저장소의 `apps-script/Code.gs`를 통째로 붙여 넣고 저장합니다.
3. 함수 목록에서 **setup**을 골라 **실행**하고 권한을 허용합니다. ("확인되지 않은 앱"이 나오면 고급 → 이동.) `설정` 시트에 **교사 가입 코드**가 생깁니다.
4. **배포 → 새 배포 → 웹 앱**, 실행 계정 **나**, 액세스 권한 **모든 사용자** → 배포. 끝이 `/exec`인 웹 앱 URL을 복사합니다.
5. 시크릿 창에서 그 URL을 열어 `{"ok":true,"service":"모델링 탐구 수행평가 API",...}`가 보이면 성공입니다. 구글 로그인 화면이나 "파일을 열 수 없습니다"가 보이면 액세스 권한 또는 계정 정책을 다시 확인합니다.

### 2. 화면 (GitHub Pages)

6. 이 저장소에서 `config.js`를 열고 연필(편집) → `apiUrl: ""`의 따옴표 안에 4번 주소를 붙여 넣고 **Commit changes**.
7. **Settings → Pages → Build and deployment**에서 Source **Deploy from a branch**, Branch **main** / **(root)** → Save. 1~2분 뒤 `https://<GitHub 아이디>.github.io/<저장소 이름>/` 주소가 생깁니다.
8. 그 주소에서 **처음이면 가입하기 → 교사이신가요?**에 교사 가입 코드를 넣어 교사 계정을 만듭니다.
9. 학생에게 같은 주소를 보냅니다. 모르는 사람의 가입을 막으려면 `설정` 시트의 **학급 코드**에 값을 넣고 학생에게만 알려 줍니다.

## 운영

- **비밀번호**: 암호화해 저장하므로 교사도 볼 수 없습니다. 학생은 [비밀번호 바꾸기]로 직접 바꾸고, 잊은 학생은 교사가 [계정·비밀번호 관리 → 비밀번호 초기화]로 임시 비밀번호를 정해 줍니다. 학생은 다음 로그인 때 새 비밀번호로 바꿉니다.
- **실시간**: 학생 글은 입력을 멈추고 2~3초 뒤 저장되고, 교사 대시보드는 10초마다 새로 고칩니다.
- **기록**: 대시보드의 [기록 스프레드시트 열기]에서 `기록`(작성률·모델 식·오차율), `채점`(요소별 점수·총점) 시트를 봅니다.
- **작성 마감**: 대시보드에서 켜면 서버가 학생 저장을 막습니다.

## 고칠 때

- **화면(`index.html`, `config.js`)**: 저장소에 커밋하면 1~2분 뒤 Pages에 자동 반영됩니다.
- **저장 서버(`apps-script/Code.gs`)**: Apps Script에 붙여 넣은 뒤 **배포 → 배포 관리 → 편집 → 버전: 새 버전 → 배포**. 주소는 그대로입니다.

저장소가 공개여도 학생 기록과 비밀번호는 스프레드시트에만 있고 저장소에는 올라가지 않습니다.
